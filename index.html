How to use DayPilot

  1. Add a task. Give it a clear name and, if useful, a due date, time, priority, and note.
  2. Choose your focus. Review today's tasks and use the filters to find high-priority work.
  3. Track progress. Mark tasks complete as you go and adjust your daily goal to fit your day.
Designed to be simple. DayPilot requires no account and has no paid API dependency. Because your task list is stored in this browser, it does not automatically sync between devices; use Export backup to keep a portable copy.

Frequently asked questions

Is DayPilot free to use?

Yes. The current planner is free to use and does not require a login or subscription.

Where are my tasks saved?

Tasks are saved in local browser storage on the device you use. Clearing browser data may remove them, so export a backup periodically.

Can I use DayPilot on my phone?

Yes. The interface is responsive and designed to work on mobile screens as well as desktop browsers.

Can I back up or move my tasks?

Use Export backup to download a JSON file, then use Import backup in the planner to restore a compatible backup.
